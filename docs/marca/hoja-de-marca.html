Reglas

  • No se rota, no se estira, no se inclina.
  • No se cambia la chispa por un corazón ni por un tenedor.
  • No se usa la chispa sola: la T dice el nombre.
  • No se escribe TUKI ni Tuki Social.
  • No se traduce el nombre propio.
  • No se pone sobre una foto sin una baldosa sólida.
  • No se usa la marca de Tuki como logo del restaurante.
  • No se añaden degradados, sombras ni contornos.
